# 东大生医常用网址

基于 [seucseWeb/seucseWeb.github.io](https://github.com/seucseWeb/seucseWeb.github.io) 的生医学院版本。

原站作者：小黑菌。原站源码版本：`d6cbc01ff1231fa255e2577a7eb473490070ea08`。

## 本次改动

- 页面标题、学院全称、印章及搜索引擎描述改为生医学院。
- 新版和旧版的学院入口由计算机学院替换为 [生物科学与医学工程学院](https://bme.seu.edu.cn/)。
- 当前为 20 个导航站点：学术 6 个、服务 7 个、资源 7 个。
- 研究生院和研究生选课已并入学术分区，物理实验中心已移除。
- 研究生院默认排列在第二位；已有排序偏好会进行一次迁移，之后仍可自行排序。
- 除学院入口替换与物理实验中心删除外，其他网址、名称和说明保持原样。
- 背景采用第二张“生医分子”插画，中央叠加原站东南大学校徽，水印透明度为 18%，并调整为浅绿色调。
- 保留搜索、收藏、最近访问、布局及版本切换；新旧版均支持添加自定义网站。
- 点击“添加网站”，填写名称、网址、分类和可选简介即可加入导航。新增网站参与搜索、收藏、最近访问和排序，支持删除。
- 自定义网站保存在当前浏览器的本地存储中，新旧版共用；清除浏览器网站数据后会丢失，也不会同步到其他设备或其他访客。
- 禁止非 HTTP/HTTPS 网址并防止重复名称和网址；网站名称和简介按文本显示。
- 原站署名明确标注为“原站作者”；邮箱和留言板仍属于原站作者。

## 文件

`dist/index.html` 是新版首页，`dist/old.html` 是旧版页面，`dist/assets/` 是原站资源。

`dist/assets/bme-background.css` 控制背景与校徽水印；`bme-molecular-bg.png` 为选定背景。

可直接打开 `dist/index.html` 查看。通过本地网站服务预览时，浏览器存储功能更稳定。

## 发布到 GitHub Pages

将 `dist/` 内的全部文件放到你自己的仓库根目录，包括 `assets/` 目录和 `.nojekyll`。
在仓库 Settings → Pages 中选择 Deploy from a branch，指定 main 分支的根目录并保存。
本版本同时提供 Sites 私有预览；私有预览地址仅供你的账号查看。

## 验证

`verification.json` 记录新版、旧版和原站的逐项对比结果。
原站已有的外部字体、图标、统计服务和 HTTP 链接均按本次要求保留。
