# 东南大学个人导航

一个以东南大学校内服务为基础、支持学院切换与浏览器本地定制的静态导航页。默认显示生物科学与医学工程学院版本，也可以切换为其他学院，并保留个人设置。

在线访问：[https://dongbaiwei.github.io/seu-BME-Web-Navigator/](https://dongbaiwei.github.io/seu-BME-Web-Navigator/)

> 本项目是非官方学生项目，与东南大学官方无隶属关系。站点链接与开放时间请以对应单位的官方信息为准。

## 主要功能

- 支持 38 个学院版本切换，可按学院全称、简称、拼音或首字母搜索。
- 切换学院后自动更新页面名称、学院官网和右侧学院主题图案。
- 内置学术、生活、服务、资源四类常用入口，并可新增、删除、移动和排序网站。
- 支持搜索、收藏、最近访问、网格/列表布局以及卡片拖拽排序。
- 支持白色、黑色、蓝色三种主题，以及学院背景、单校徽、纯色和自定义图片壁纸。
- 背景设置采用实时预览面板，可直接观察主题、校徽和学院图案的变化。
- 资源区提供“实用项目与脚本”友情链接列表。
- 全部个人设置保存在当前浏览器，刷新或再次打开后继续保留。

## 个人定制

顶部只保留三个主要入口：

- **学院**：切换学院版本。
- **个人设置**：管理分类、页面标题、显示内容、卡片外观和背景。
- **添加网站**：将个人常用网站加入任意分类。

个人设置包含：

| 设置 | 可调整内容 |
| --- | --- |
| 分类管理 | 新增、重命名、隐藏、排序和删除分类，移动网站，进入导航管理模式 |
| 页面标题 | 使用学院默认标题或填写个人标题 |
| 显示设置 | 时钟、学院说明、校训、底部装饰、实用项目列表 |
| 卡片外观 | 卡片密度、桌面列数、圆角、透明度和毛玻璃强度 |
| 背景设置 | 主题、壁纸、背景明暗、校徽浓度、学院图案浓度与显示开关 |

更完整的使用与实现说明见[个人定制说明](个人定制说明.md)。

## 本地运行

这是一个无需构建工具的静态网站。下载或克隆仓库后，在仓库目录启动任意静态文件服务器即可。例如：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

直接双击 `index.html` 也可以查看页面，但使用本地服务器时，浏览器存储和资源加载更稳定。


## 数据与隐私

学院选择、自定义分类、页面标题、卡片外观、自定义网站、收藏、访问记录和上传壁纸均保存在浏览器的本地存储中，不会上传到服务器。

因此：

- 不同浏览器和设备之间不会自动同步。
- 清除该网站的浏览器数据会删除个人设置。
- GitHub 仓库中的更新不会覆盖访问者已经保存的个人设置。

## 部署

仓库使用 GitHub Pages 部署。在 **Settings → Pages** 中将发布来源设置为：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

推送到 `main` 后，GitHub Pages 会自动更新。
